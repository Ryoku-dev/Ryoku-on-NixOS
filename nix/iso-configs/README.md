# Ryoku ISO configuration

This directory is the canonical `/etc/nixos` layout installed by the Ryoku ISO.
The installer copies these files and generates only `install-values.nix` plus
NixOS's normal `hardware-configuration.nix`.

## Files

- `flake.nix` tracks the normal Nixpkgs/Ryoku branches; the generated
  `flake.lock` pins the exact revisions tested by the installer image.
- `configuration.nix` owns general NixOS settings, boot, networking, locale,
  the selected kernel policy, and the installed user.
- `ryoku.nix` contains Ryoku desktop choices.
- `pkgs.nix` is the user-editable package list.
- `install-values.nix` is the small machine-specific file generated by the
  installer, including hostname/user locale choices, GPU list, kernel policy,
  and Ryoku desktop selections.
- `hardware/gpu/` contains vendor-specific GPU defaults. Hybrid systems may
  import more than one vendor module.
- `modules/` is available for additional user modules.

Rebuild with:

```bash
sudo nixos-rebuild switch --flake /etc/nixos#ryoku
```

Update flake inputs and rebuild with:

```bash
sudo nix flake update --flake /etc/nixos
sudo nixos-rebuild switch --flake /etc/nixos#ryoku
```
