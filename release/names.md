# Release names

Every release line carries a name from the creation stories Ryoku draws on,
the Kojiki and the Theogony, in the order those stories tell them: each line
is the next thing that came to be. The current name is the one line in
`CODENAME`; it changes when a line begins and every release inside the line
keeps it. `ryoku version --pretty`, `/etc/ryoku-release`, the update island,
the Hub's Updates page, the release ledger and the GitHub release all carry
it, and the first release of a line opens its notes with the section below.

## Onogoro

Before there was land, Izanagi and Izanami stood on the floating bridge of
heaven and stirred the sea with the jewelled spear. The brine that dripped
from its tip piled up and set: Onogoro, the island that formed itself, the
first solid ground. Everything after was made standing on it. This line is
that ground: the first releases with a name, a channel, and a way back.

## Amaterasu

Once the land was made, Izanagi washed the world from his eyes and the sun
was born: Amaterasu, the light everything after runs under. The 1.0 line: a
power release, the system made whole.
